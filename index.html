WEBMCP LEVERAGE

The website becomes an agent tool surface.

Instead of asking an agent to guess where to click, GoPic registers structured actions directly with document.modelContext.

TOOL 01gopic_get_sign_context

Read the current human-provided photo context and location hint.

read-only · current page state
TOOL 02gopic_analyze_sign

Run the GoPic sign-analysis workflow and return structured findings.

vision → OCR → candidate grounding
TOOL 03gopic_get_place_candidates

Inspect candidate places and the evidence used to distinguish namesakes.

read-only · grounded candidates
WebMCP availability is detected at runtime. The page remains usable by humans even when the experimental browser API is unavailable.
